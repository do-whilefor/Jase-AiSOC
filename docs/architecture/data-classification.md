# 数据分类与处理基线

| 级别 | 示例 | 默认处理 | 外部模型 |
|---|---|---|---|
| D0 公开 | 公开规则 ID、公开 CVE、产品文档 | 可公开；保留完整审计 | 允许 |
| D1 内部 | 非敏感资产标签、聚合指标、组件版本 | 认证访问；按租户隔离 | 经租户策略允许，可发送最小字段 |
| D2 机密 | IP/主机名、用户标识、命令行、URL、内部拓扑、事件详情 | 加密、最小权限、字段级脱敏、限期保留 | 默认禁止；仅本地模型或经审批的专用 Provider，禁止原始凭据和完整文件内容 |
| D3 受限 | 凭据、Token、私钥、完整原始日志、PCAP、文件内容、恶意样本、身份/金融/医疗数据 | 独立授权、不可执行/隔离存储、下载审计、短期授权、严格生命周期 | 默认禁止；只有显式政策和字段白名单可例外 |

## 处理规则

1. 采集前确定目的、必要字段、保留期和可见角色；未知分类默认按 D3。
2. `tenant_id`、资产关键度、证据定位符和响应权限属于受信控制字段，不能由不可信事件覆盖。
3. 日志输出只记录标识符、计数和脱敏摘要，不记录密钥、认证头、完整样本或未经筛选的模型上下文。
4. 原始证据与 AI 输入输出分开保存；AI 记录保留 Provider、模型、Prompt/策略版本、字段清单、Token、成本和结果哈希。
5. 对象存储按租户/数据类型分区，样本桶不可执行；访问使用短期凭据并记录下载审计。
6. 删除必须覆盖索引、对象、缓存和派生模型上下文，并保留不含敏感原文的删除审计。

## AI 数据出域门禁

发送外部 Provider 前依次执行：租户策略允许 -> 数据分类允许 -> 字段白名单 -> 脱敏/截断 -> 预算检查 -> 调用审计。D2（机密）与 D3（受限）数据默认阻断外部模型；日志中的任何指令性文本都必须作为引用数据封装，不能进入系统指令。
